# 출시 노트 (Play Store)

> Play Console → 프로덕션 → 새 버전 → "출시 노트" 에 붙여넣기.
> 언어당 최대 500자. 버전마다 `<ko-KR>` 블록 내용만 교체.

---

## v1.0.0 (versionCode 2) — 첫 출시

```
망고샵 첫 출시 🥭

전국 수입사가 입점한 수입 과일 도매·소매 오픈마켓을 모바일에서 만나보세요.

• 태국·베트남·필리핀 애플망고부터 아보카도·열대과일까지, 검증된 수입사의 신선한 과일
• 원산지·품종·등급·규격을 한눈에, 콜드체인 냉장배송
• 도매(사업자) 회원은 승인 후 도매가와 수량별 할인가로 대량 구매
• 장바구니·간편결제·무통장입금, 쿠폰과 적립금 혜택
• 관심상품, 상품후기, 1:1 문의와 실시간 상담

신선한 수입 과일을 합리적인 가격에 주문해 보세요!
```

**짧은 버전(대안)**
```
수입 과일 도매·소매 오픈마켓 망고샵이 출시되었습니다 🥭
검증된 수입사의 애플망고·아보카도·열대과일을 콜드체인으로 신선하게.
도매 회원은 도매가와 수량별 할인가로 대량 구매하세요.
장바구니·간편결제, 쿠폰·적립금, 상품후기와 1:1 상담까지 한 앱에서.
```

